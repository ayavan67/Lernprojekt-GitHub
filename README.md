# Lernprojekt-GitHub

## Ziel

In diesem Projekt übe ich, Aufgaben mit GitHub Issues,
einem Project-Board und einem Milestone zu organisieren.

## Projektstruktur

- README.md: Beschreibung des Projekts
- src/index.html: Einfache HTML-Beispielseite

## Beispielseite öffnen

Die Datei src/index.html herunterladen und im Browser öffnen.

## Arbeitsablauf

1. To Do: Die Aufgabe ist noch offen.
2. In Progress: Die Aufgabe wird bearbeitet.
3. Review: Das Ergebnis wird kontrolliert.
4. Done: Die Aufgabe wurde geprüft und abgeschlossen.

## Meilenstein

Der Milestone Projektsetup umfasst die Projektstruktur,
die README und den Feedbackprozess.
