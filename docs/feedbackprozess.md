# Feedbackprozess

## Ablauf

1. Eine Aufgabe wird als Issue erstellt und einer Person zugewiesen.
2. Bei Arbeitsbeginn wird die Karte nach In Progress verschoben.
3. Sobald das Ergebnis bereit ist, kommt die Karte nach Review.
4. Ein Teammitglied prüft die Änderungen auf Fehler und Verständlichkeit.
5. Feedback wird als Kommentar im Issue festgehalten.
6. Falls Änderungen nötig sind, geht die Karte zurück nach In Progress.
7. Nach erfolgreicher Prüfung wird ein Abschlusskommentar geschrieben,
   das Issue geschlossen und die Karte nach Done verschoben.

## Regeln für Feedback

- Freundlich und sachlich bleiben.
- Genau beschreiben, welche Stelle verbessert werden soll.
- Wenn möglich einen Verbesserungsvorschlag machen.

## Einzelarbeit

Bei dieser Übung wird die Kontrolle selbst durchgeführt.
Dabei werden die Dateien nochmals geöffnet und geprüft.
